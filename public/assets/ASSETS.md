# Original pixel placeholders

24 original, code-drawn SVG assets; no third-party artwork, fonts, or proprietary UI assets. Created for SpaceAgriculture. These assets are dedicated under CC0-1.0 (https://creativecommons.org/publicdomain/zero/1.0/).

All sprites use a transparent 32 × 32 viewBox, whole-pixel shapes, and a shared muted palette. Render at integer multiples with image-rendering: pixelated. Module ground contact: (16, 28); these are placeholders, not final isometric footprints. Developer A owns texture loading, rotation, depth sorting, and placement geometry. UI PixelAsset has a visible fallback on load error.

Crops: lettuce, potato, wheat.
Animals: chicken, pig, cow.
Hazards: temperature, radiation, micrometeoroid, communications, power.
